### about

20, from Kerala.

I like building things close to the boundary between **software and hardware**.

AI, systems, electronics, EDA, embedded stuff, compilers, computer vision,  
reverse engineering, and occasionally a completely unrelated rabbit hole at 3 AM.

I don't really have a preferred layer of the stack.
